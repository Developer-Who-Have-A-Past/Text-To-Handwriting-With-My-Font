# Adding your handwriting

1. Go to https://www.calligraphr.com, print the free template, write each character in your own pen, scan/photo it and upload.
2. Build the font and download the `.ttf`.
3. Rename it to `MyHandwriting.ttf` and put it in this folder (`fonts/`).
4. Reload the site: "My Handwriting" appears in the Handwriting Font dropdown.
